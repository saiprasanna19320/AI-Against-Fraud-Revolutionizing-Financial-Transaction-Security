
# AI AGAINST FRAUD: REVOLUTIONIZING FINANCIAL TRANSACTION SECURITY

## Project Overview

AI Against Fraud is a machine learning-based project focused on identifying potentially fraudulent and abnormal financial transactions.

The project explores data analysis, anomaly detection and interactive visualization to support financial transaction security.

## Objectives

- Analyze financial transaction data.
- Identify unusual transaction patterns.
- Apply machine learning techniques for anomaly detection.
- Visualize transaction insights through an interactive web application.
- Explore the use of AI in financial fraud detection.

## Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Isolation Forest
- PCA
- Matplotlib
- Seaborn
- Streamlit
- Jupyter Notebook

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/saiprasanna19320/AI-Against-Fraud.git
```

### 2. Navigate to the project folder

```bash
cd AI-Against-Fraud
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```

## Machine Learning Approach

The project uses Isolation Forest for anomaly detection in financial transaction data.

Additional data processing and analysis techniques include:

- Handling skewed numerical features.
- Feature preprocessing.
- Principal Component Analysis (PCA).
- Exploratory data analysis and visualization.

## Project Files

- `Fraud_Detection.ipynb` – Jupyter Notebook containing the analysis and machine learning workflow.
- `app.py` – Streamlit web application.
- `bank_transactions_data_2.csv` – Financial transaction dataset.
- `requirements.txt` – Python dependencies.
